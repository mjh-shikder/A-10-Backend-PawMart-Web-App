# PawMart Backend 🐾

This is the backend server for **PawMart**, a community-driven pet adoption and pet product marketplace.  
The server is built with **Node.js**, **Express.js**, and **MongoDB**, providing secure and efficient APIs for the PawMart client application.

## 📌 Features

- 🔗 **RESTful API Endpoints** to manage pets, products, orders, and users.
- 🗂️ **MongoDB Database Integration** using the official MongoDB Node driver.
- 🌐 **CORS Enabled** for seamless communication with the frontend client.
- 🔒 **Environment Variable Support** using `dotenv`.
- ⚡ **Fast & Lightweight Express Server** optimized for real-time interactions.
- 📄 **CRUD Operations** for listings, recent items, categories, and orders.
- 📨 **Email Field Auto-Population** and filtering support.
- 🧪 **Error Handling & Validation** for stable backend performance.
